# Data

`sample_schedule.csv` is a **fully synthetic** procedure-room schedule
covering 5 rooms over 60 weekdays (~1,250 cases), generated by
[`scripts/generate_sample_data.py`](../scripts/generate_sample_data.py).

It is built to have realistic statistical properties — a ~6% cancellation
rate, cascading delays across the day, procedure-specific duration
distributions, and randomized turnaround gaps — but contains **no real
patient, surgeon, or hospital data of any kind**. Surgeon IDs are
auto-generated placeholders (`SUR-001`, etc.) and procedure names are
generic (e.g. "Total Knee Arthroplasty").

Regenerate it anytime with a different seed, room count, or day count:

```bash
python scripts/generate_sample_data.py --out data/sample_schedule.csv --days 60 --rooms 5 --seed 42
```

To use your own real scheduling export instead, see the **Bring your own
data** section of the top-level [README](../README.md) for the expected
column schema.
